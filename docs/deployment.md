# Развёртывание учебного сервиса

Docker Compose запускает Next.js и FastAPI. SQLite сохраняется в именованном томе, а необязательный артефакт модели подключается с хоста только для чтения. Образы не содержат .env, рабочую БД, исходный MovieLens или обученную модель.

## Подготовка

Нужны Docker с Compose v2 и два соседних каталога:

```text
workspace/
  movie_model_backend/
  movie_model_frontend/
```

Если репозитории ещё не скачаны:

```sh
git clone https://github.com/Arsgaz/movie_model_backend.git
git clone https://github.com/Arsgaz/movie_model_frontend.git
cd movie_model_backend
```

Создайте .env из .env.example, если его ещё нет. Существующий .env сохраняйте. Для поиска, карточек и content-рекомендаций укажите MOVIE_TMDB_API_KEY. Этот ключ не требуется при сборке образов и не передаётся фронтенду.

Compose задаёт собственный MOVIE_DATABASE_URL с абсолютным путём /app/data/movie_model.sqlite3. Локальная SQLite разработчика не переносится в контейнер автоматически. Браузер и контейнеры используют разные адреса: Next.js обращается к http://backend:8000 внутри Compose, пользователь открывает localhost.

## Базовый запуск

Из каталога бэкенда:

```sh
docker compose up --build -d --wait
```

| Адрес | Назначение |
| --- | --- |
| http://localhost:8080 | Интерфейс |
| http://localhost:8081/docs | Swagger API |
| http://localhost:8081/health | Проверка процесса |
| http://localhost:8081/ready | Готовность схемы БД и статус модели |

По умолчанию модель отключена явным пустым MOVIE_RECOMMENDATION_MODEL_PATH, даже если в локальном .env указан путь к артефакту. Готовность API при доступной БД остаётся успешной, model=not_configured. Content и popularity используют TMDB; без ключа и модели рекомендации недоступны. Локальные процессы на 3000/3100 и 8000 этим запуском не заменяются.

## Запуск с моделью

Подготовьте совместимый каталог артефакта с manifest.json, movies.json, similarities.npz и popularity.npy. Для текущей версии он находится в artifacts/recommendations/movielens-32m-v1/model. Обучение описано в [документации ML](machine-learning.md).

```sh
docker compose -f compose.yaml -f compose.model.yaml up --build -d --wait
```

Дополнительный Compose-файл подключает каталог как /models/active только для чтения. Отсутствующий каталог вызывает ошибку запуска, а не создаётся автоматически. Контрольные суммы и допустимость артефакта проверяет приложение. /ready должен показывать model=ready; невалидный артефакт даёт model=unavailable, но не отключает остальные методы API.

Для другого каталога задайте MOVIE_MODEL_HOST_PATH в окружении или .env. Для другого расположения фронтенда — MOVIE_FRONTEND_PATH. Порты меняются через MOVIE_WEB_PORT и MOVIE_API_PORT (по умолчанию 8080 и 8081). При изменении настроек повторите up -d --wait с теми же Compose-файлами: простой restart не перечитывает переменные контейнера.

## Сохранность и обслуживание

Перед запуском API entrypoint выполняет alembic upgrade head. Ошибка миграции останавливает контейнер. Используется один процесс Uvicorn и одна реплика бэкенда; этот вариант предназначен для локального учебного показа с SQLite.

```sh
docker compose ps
docker compose logs --tail=100 backend frontend
docker compose restart backend frontend
docker compose down
```

Для конфигурации с моделью используйте тот же набор -f compose.yaml -f compose.model.yaml в командах управления. down удаляет контейнеры и сеть, сохраняя том БД. Не добавляйте --volumes, если нужно сохранить оценки и профили. Артефакт на хосте не меняется при остановке контейнеров. После замены артефакта перезапустите бэкенд, чтобы он загрузил новую версию.

Для резервной копии SQLite остановите бэкенд и скопируйте файл из /app/data; не копируйте работающую БД без механизма согласованного backup. Перед обновлением миграций сохраните резервную копию. Миграции не означают автоматический безопасный откат версии схемы.

## Проверка полного сценария

1. Дождитесь healthy у обоих сервисов; проверьте /ready и ожидаемый статус модели.
2. Создайте отдельный демонстрационный профиль в интерфейсе.
3. Найдите фильмы через каталог и поставьте несколько оценок, включая 1–2 и 4–5.
4. Откройте «Для вас»: проверьте отсутствие оценённых фильмов и доступность карточек.
5. В «Удиви меня» запросите следующую подборку; между запросами возможны повторы.
6. Перезапустите сервисы и убедитесь, что профиль, оценки и избранное сохранились.

Эта проверка подтверждает интеграцию и сохранность данных. Она не заменяет offline-оценку качества модели и не даёт метрики точности гибридного ранжирования.

## Границы развёртывания

Порты привязаны к 127.0.0.1 хоста. Профили не защищены авторизацией; текущая конфигурация рассчитана на локальную демонстрацию. Внешнее размещение потребует отдельной настройки доступа и HTTPS. Доступность TMDB и CDN нужна для каталога и постеров; /ready не проверяет сетевую доступность TMDB.

Фронтенд собирается в [режиме Next.js standalone](https://nextjs.org/docs/app/api-reference/config/next-config-js/output) и запускает server.js. Runtime содержит standalone, public и .next/static. Переменная BACKEND_API_URL задаётся при запуске. Порядок старта опирается на [Compose service_healthy](https://docs.docker.com/compose/how-tos/startup-order/).
